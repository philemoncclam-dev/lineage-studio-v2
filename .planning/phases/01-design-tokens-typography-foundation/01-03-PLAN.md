<objective>
Build the token-to-canvas bridge: a typed snapshot of every token the canvas renderers
need, read once from the DOM, cached at module scope, and invalidated only on a real
`data-theme` change. Then remove the per-frame `getComputedStyle` calls that the knowledge
graph's draw loop makes today.

Purpose: THEME-03 is a named performance trap, not a style preference. `GraphView.tsx`
currently calls `getComputedStyle(document.documentElement)` six times per node and twice
per edge, inside a `requestAnimationFrame` loop — each call forces a full-document style
recomputation, and the cost scales with node count. This plan establishes the pattern that
Phase 3's xyflow renderers and Phase 4's sigma.js reducers must both follow.

Output: `frontend/src/tokens/canvasTokens.ts` and a `GraphView.tsx` draw loop that reads
zero styles.
</objective>

    - After the `data-theme` attribute on the document element changes, the next
      `getCanvasTokens()` call returns a fresh object with the new theme's values.

    - Every member of the ColorKey union maps to a non-empty token value.
    - `invalidateCanvasTokens()` forces the next read to re-read the DOM.

  <action>
    Create `frontend/src/tokens/canvasTokens.ts`, TypeScript strict, exporting:

    - `interface CanvasTokens` — one readonly string field per token a canvas or SVG
      renderer needs and nothing it does not. Cover: the canvas surface, the grid-dot
      colour, the three text tiers, the border and border-strong tokens, all three accent
      steps, all four domain colours plus the neutral fallback domain, all three edge
      colours, and the two font families and four type sizes. Field names are camelCase
      mirrors of the token names (for example the canvas surface token becomes
      `surfaceCanvas`).
    - `const DOMAIN_TOKEN: Record<ColorKey, keyof CanvasTokens>` — an exhaustive mapping
      from the `ColorKey` union in `frontend/src/data.ts` to the snapshot field that paints
      it. Map bronze, silver, gold and notebook to their domain fields; map the accent key
      to the accent field; map the workspace key to the neutral domain field, which is the
      destination for `colorFor`'s fallback branch and matches the neutral default the DOM
      tick indicator already renders. Because the record is typed over the full union,
      adding a domain later is a compile error rather than a runtime blank.
    - `function getCanvasTokens(): CanvasTokens` — returns the module-scope cache,
      populating it on first call by reading `getComputedStyle(document.documentElement)`
      once and pulling every property from that single computed-style object. Trim each
      value. If any required property comes back empty, throw with the offending token
      name rather than returning a snapshot containing an empty string — a blank fill
      style paints invisibly and would be a silent failure.
    - `function invalidateCanvasTokens(): void` — clears the cache.
    - `function initCanvasTokenCache(): () => void` — registers a `MutationObserver` on the
      document element filtered to the `data-theme` attribute, whose callback calls
      `invalidateCanvasTokens`. It is idempotent: a second call must not register a second
      observer. It returns a disconnect function. This is wired once at bootstrap.

    Also export a small helper that builds a canvas `font` shorthand string from a weight,
    one of the four type sizes, and one of the two families, so draw calls never
    concatenate a raw pixel literal. Only the two sanctioned weights are accepted — type
    the weight parameter as the literal union of 400 and 600.

    Do not add a polling interval, a storage listener, or a per-consumer re-check. The
    attribute observer is the single invalidation path, and per the UI-SPEC it must run as
    the theme toggle's last step — Phase 2's shell inherits that contract.
  </action>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DOM computed style → JS render state | Rendering decisions are taken from values read out of the document, cached across frames |
| `data-theme` attribute mutation → cache invalidation | An attribute change is the sole trigger for re-reading presentation state |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-11 | Denial of service | `getComputedStyle` inside the per-frame draw loop | high | mitigate | The current draw loop forces a full-document style recomputation up to eight times per node per frame; on estate-scale graphs this is a self-inflicted render stall that worsens with node count. Mitigated by a single module-scope snapshot read, an acceptance criterion asserting zero `getComputedStyle` calls outside the bridge module, and exactly one call site inside it. |
| T-01-12 | Spoofing | Empty token value painting invisibly | medium | mitigate | An undeclared or renamed token resolves to an empty string, which the canvas silently accepts as a no-op fill — content vanishes with no error. Mitigated by the snapshot throwing on any empty required value, and by an acceptance criterion cross-checking every token name read by the module against the declarations in tokens.css. |
| T-01-13 | Tampering | `MutationObserver` on the document element | medium | mitigate | The observer is filtered to the single `data-theme` attribute and its callback only clears a cache — it performs no DOM writes and evaluates no attribute content, so a mutation cannot drive behaviour beyond a re-read. The initialiser is idempotent so repeated bootstrap cannot stack observers. |
| T-01-14 | Elevation of privilege | Attribute-driven code path | low | accept | The observer callback takes no argument-derived branch; any actor able to set the attribute already has full DOM access, so no privilege boundary is crossed. |
| T-01-15 | Information disclosure | Cached presentation snapshot | low | accept | The snapshot holds only static colour, font and size strings; it carries no user, tenant or catalog data. |
</threat_model>

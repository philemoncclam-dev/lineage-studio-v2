<objective>
Decompose the 228-line `src/model.tsx` monolith into four pure modules
(`adapt` / `lineageLayout` / `graphLayout` / `domainColor`) plus an
`index.tsx` composition root, behind an unchanged `./model` import surface.
This is the phase goal's "decomposed pure layout model" — the shared
cross-canvas plumbing both Phase-3 and Phase-4 canvas rebuilds depend on.

Purpose: `model.tsx` currently mixes object-level op classification, layered
DAG layout, knowledge-graph topology, and domain colour in one function that
cannot be unit-tested piecewise. Splitting along its own comment boundaries
makes each concern directly testable and gives Phases 3-4 clean seams to
consume. This is a behavior-preserving refactor (workstream B in
02-CONTEXT.md D-14, explicitly allowed to run as a parallel plan) — the app
stays demoable throughout (SHELL-07).

Output: `src/model/` directory with four pure modules + `index.tsx`, unit
tests proving output parity, and `src/model.tsx` deleted. No consumer import
changes.
</objective>

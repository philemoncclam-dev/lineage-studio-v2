(D-06/D-07), a root loader that fetches the graph once with sample fallback,

structural change of the phase.

(SHELL-05) and back/forward walks drill levels correctly (SHELL-06). The
selection search-param design IS the "shared cross-canvas plumbing" both
Phase-3 and Phase-4 canvases consume. At the end of this plan the app runs on
the router with the old canvases rendered inside the new shell root — still
demoable (SHELL-07).

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | validateSearch(?sel,?col) | medium | mitigate | Zod `selectionSchema` validates/coerces every search param before it reaches components; a malformed shape (e.g. `?sel[]=x&sel[]=y`) is rejected/coerced by `.optional()` string typing, never passed through unchecked |
| T-02-02 | Information Disclosure | D-09 unresolved-segment notice | medium | mitigate | The failed-segment string is rendered as a plain JSX text child (React auto-escapes) — never `dangerouslySetInnerHTML`; interpolated segment is length-bounded |
| T-02-03 | Tampering | navigate/redirect targets | low | accept | All navigation targets are built only from the app's own route definitions and resolved graph node names, never from an arbitrary user-supplied absolute URL — no open-redirect surface |
</threat_model>

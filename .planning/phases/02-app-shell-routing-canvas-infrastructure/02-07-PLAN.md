<objective>
Fix the confirmed, reproducible blank-screen crash (CR-01 / Gap #1) that falsifies SHELL-07 and ROADMAP Success Criterion #6 ("the app remains usable and demoable at every commit").

Root cause (confirmed three ways — deferred-items.md Playwright repro, 02-REVIEW.md CR-01, verifier's node_modules trace): the root route's Suspense `pendingComponent` (`RootPending` in `src/routes/__root.tsx`) renders `<AppShell>`, which unconditionally mounts `<Inspector/>` and `<CommandPalette/>`. `Inspector` calls `useSelection()` → `useSearch({ strict: false })` → `useMatch()`; `CommandPalette` calls `getRouteApi('__root__').useLoaderData()` → `useMatch()`. TanStack Router's `Matches()` provides `matchContext` only to the Suspense primary children, never to the `pendingComponent` fallback slot, so `useMatch` throws `Invariant failed: Could not find a nearest match!`. Because the root loader's `fetchGraph()` is a real network call, the pending state renders on effectively every load — the app blank-screens.

Purpose: Restore the phase's own load-bearing guarantee (never leave the app broken) so Phases 3-4 build on a demoable base, and unblock the live-browser human verification that CR-01 has been blocking.
Output: A pending/loading state that mounts zero match-context-reading components, a regression test that reproduces-then-guards the crash, and a live both-theme paint confirmation.
</objective>

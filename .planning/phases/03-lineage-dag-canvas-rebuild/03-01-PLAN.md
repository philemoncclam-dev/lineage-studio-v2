<objective>
Deliver the D-12 scoped, additive backend evidence thread that TRUST-02's inspector Evidence section will render: extend the `ColumnMap` contract with an optional `ColumnMapEvidence` (notebook, cell_index, line, snippet), populate it in `parser.py` from the existing `_SELECT_RE` match, and mirror the field in the frontend's `api.ts` interface — all backward-compatible so existing manual-JSON payloads still parse.

Purpose: The verbatim matched-cell snippet is the honest evidence behind every inferred column edge (pitfall #6). It must be computed once at parse time (only the backend has the raw cell text + regex match) and threaded over the stable `LineageGraph` contract.
Output: `ColumnMapEvidence` model, evidence-populating parser, mirrored TS interface, and pytest coverage proving both population and backward compatibility.
</objective>

|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering (V5 Input Validation) | ColumnMapEvidence field shape | low | mitigate | Pydantic validates the field's shape/types on parse; evidence is a typed model, not free-form dict |
| T-03-02 | Information Disclosure / EoP (script text carried as data) | evidence.snippet = raw cell text | high | transfer | The snippet may contain arbitrary notebook text incl. `<script>`; it is NEVER rendered as HTML here (backend serves JSON).

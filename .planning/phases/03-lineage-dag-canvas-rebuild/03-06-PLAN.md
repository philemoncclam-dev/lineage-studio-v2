    - Given an ordered focus-target list (each with id, kind 'header'|'row', rank, cardId, and colKey for rows), resolveNextFocus(targets, current, 'ArrowDown', colEdges) returns the next row in the same card, then the first row/header of the next card in the same rank at the card boundary.
    - resolveNextFocus(..., 'ArrowUp', ...) is the exact inverse.
    - resolveNextFocus for 'ArrowRight' on a header target returns the first focusable target in the next rank; 'ArrowLeft' the previous rank.
    - resolveNextFocus for 'ArrowRight' on a row target with a downstream colEdge returns the target whose colKey is the first downstream connected column (path-walk); 'ArrowLeft' returns the first upstream column's target.
    - resolveNextFocus for 'Home'/'End' returns the first/last target.
    - 'Tab'/'Shift+Tab' return null (not handled — focus leaves the canvas).
  </behavior>
